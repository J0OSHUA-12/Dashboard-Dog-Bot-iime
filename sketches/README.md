# Mis sketches

Carpeta de trabajo del editor de Dog Bot Control. Cada sketch vive en
`sketches/<Nombre>/<Nombre>.ino` (Arduino exige que la carpeta y el archivo
tengan el mismo nombre). "Guardar copia" desde un original o desde el firmware
del dashboard crea aquí un archivo nuevo; los originales de
`DOGBOT_CLAUDE_CODE/originales/` nunca se sobrescriben.
